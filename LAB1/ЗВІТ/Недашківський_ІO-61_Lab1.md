## Завдання

Задано дійсне число x. Визначити значення заданої за варіантом кусково-неперервної функції y(x), якщо воно існує, або вивести на екран повідомлення про неіснування функції для заданого x.

Розв'язати задачу двома способами:

1. Використовуючи тільки одиничні операції порівняння без булевих логічних операцій.
2. З обов'язковим використанням булевих логічних операцій.

### Варіант 19

Для заданого дійсного x обчислити:

- `f1(x) = -9x³ + 5x²`, якщо `x ∈ (2; 12] ∪ (22; 32)`
- `f2(x) = -x² - 12`, якщо `x ∈ (-∞; 0]`

Для інших значень x функція не визначена.

## Програмний код

### Перший розв'язок

```c
#include <stdio.h>
int main(void){
    double x, y;
    scanf("%lf", &x);
    if (x <= 0) {
        y = -(x*x) - 12;
        printf("y = %lf\n", y);
    } else if (x <= 2) {
        printf("Function not defined\n");
    } else if (x <= 12) {
        y = -9 * x * x * x + 5 * x * x;
        printf("y = %lf\n", y);
    } else if (x <= 22) {
        printf("Function not defined\n");
    } else if (x < 32) {
        y = -9 * x * x * x + 5 * x * x;
        printf("y = %lf\n", y);
    } else {
        printf("Function not defined\n");
    }
    return 0;
    }
```

### Другий розв'язок

```c
#include <stdio.h>
int main(void){
    double x, y;
    scanf("%lf", &x);
    if ((x > 2 && x <= 12) || (x > 22 && x < 32)) {
        y = -9 * x * x * x + 5 * x * x;
        printf("y = %lf\n", y);
    } else if (x <= 0) {
        y = -(x*x) - 12;
        printf("y = %lf\n", y);
    } else {
        printf("Function not defined\n"); }
    return 0;}
```
